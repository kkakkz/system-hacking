## The Stack
지금까지 배운 메모리 접근 (`[address]`,`[rax]`,오프셋, 이중 역참조)은 전부 "고정되거나 임의의"메모리 주소를 다뤘다.
하지만 이제부터 다룰 **스택**은 **프로그램 자체가 함수 호출, 지역 변수, 리턴주소를 저장하는데 실제로 쓰는 메모리 영역**이다.
이전 Memory 강의 에서 이미 `push`/`pop`이 `rsp`를 8씩 증감시키며 스택에 값을 쌓고 꺼낸다는걸 배웠는데, 이번 The Stack은 그걸 **실전 프로그램 관점**(함수 호출, 스택 프레임)에서 다시 다지는 단계이다.

이번 강의가 사실상 최종 목표로 하는 **버퍼 오버플로우(BOF)**의 무대 그 자체이다. 스택 구조와 `rsp`의 동작을 확실히 알아야, "스택에 있는 버퍼를 얼마나 넘치게 써야 리턴 주소까지 덮을 수 있는지" 계산할 수 있다.
